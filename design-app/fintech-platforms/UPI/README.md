# Unified Payments Interface (UPI)

## Overview

The **Unified Payments Interface (UPI)** is India's real-time payment system developed by the National Payments Corporation of India (NPCI). It enables instant bank-to-bank money transfers using mobile devices without requiring bank account details for every transaction.

This handbook explains UPI from first principles through production-scale architecture, making it useful for software engineers, system designers, and interview preparation.

---

## Objectives

- Understand the evolution of digital payments in India.
- Learn the architecture of the UPI ecosystem.
- Understand the responsibilities of NPCI, PSPs, TPAPs, and Banks.
- Study complete transaction flows.
- Learn security, settlement, and failure handling.
- Understand scalability and production engineering considerations.
- Design a simplified UPI-like system.
- Prepare for Senior, Lead, and Principal-level system design interviews.
