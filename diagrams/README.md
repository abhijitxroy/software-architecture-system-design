## Diagram Standards

Recommended structure:

```text
Requirements
↓
Architecture
↓
Components
↓
Data Flow
↓
Scaling
↓
Reliability
↓
Tradeoffs
```

Diagram guidelines:

- Keep diagrams simple
- Use top to bottom flow
- Show bottlenecks
- Show scaling components
- Show failure handling
- Keep naming consistent
- Show failure points
- Prefer production flow
